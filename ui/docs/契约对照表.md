## 页面 ↔ 接口映射

### ① 概览页 (`/overview`)
- `GET /health` → 显示 ok/version/milestones

### ② 自动化列表 (`/automations`)
- `GET /graphs` → 列表（name, latest_version, saved_at, note, **mode**, **automation_ids**）
- `GET /conf/_all` → 置信度 badge（automation_id/confidence/band），按 automation_id 去重聚合
- 搜索过滤：按 name / note 模糊匹配
- **归档名 ↔ automation_ids 映射**：见下方「归档名 ↔ automation_ids ↔ 置信度映射」分页段

### ③ 自动化详情 (`/automations/:name`)
- `GET /graphs/{name}` → IR 原文 + NL 文本（原样展示）+ diagnostics
- `<SafetyAlert>` 组件：诊断含 L3_ACTION/SHADOW_WRITES_DEVICE/LOW_CONF_WRITES_DEVICE/L2_NEEDS_CONFIRM 时显示
- `<DiagnosticPanel>` 组件：error 红色 / warning 黄色分级展示

### ④ 仿真回放 (`/simulation`)
- IR/Seed/Events 文本框编辑
- `POST /sim` → 实例轨迹 + 审计 + 最终状态 + NL 结果
- 轨迹时间线、审计列表、状态表

### ⑤ 置信度面板 (`/confidence`)
- `GET /conf/{name}` → items + thresholds（按 automation_id 过滤）
- `GET /conf/_all` → 聚合置信度（按 automation_id 去重）
- 阈值可视化条：auto ≥ 0.85 / shadow ≥ 0.60 / ask < 0.60
- "模拟人工干预"按钮 → `POST /conf/{name}/intervene`

### ⑥ 版本与 Diff (`/versions`)
- `GET /graphs` → Graph 名称下拉
- 旧版/新版选择器
- `GET /diff?name=&old=&new=` → 人类可读 diff + 结构化 diff

### ⑦ AF-Spec 工作台 (`/spec-editor`)
- 左侧：文本编辑器（预填示例 Spec）
- 右侧：编译结果
- `POST /spec/compile` → IR + NL + Diagnostics

### ⑧ 故障注入图鉴 (`/faults`)
- `GET /faults` → kinds（五类）+ failures（四类）

## 归档名 ↔ automation_ids ↔ 置信度映射

> Round 2 真后端联调新增分页段。归档名（`/graphs` → `name`）与自动化 id（`/conf` → `automation_id`）通过 `automation_ids[]` 字段建立映射。

### 映射关系

| 归档名 (graph name) | mode | automation_ids[] | 置信度 (confidence) | Band | 数据来源 |
|---------------------|------|-------------------|---------------------|------|----------|
| `study_day_light` | restart | `["study_day_light"]` | 0.92 | auto | Mock + 真后端 |
| `study_leave_light` | restart | `["study_leave_light"]` | 0.78 | shadow | Mock + 真后端 |
| `night_desk_lamp` | single | `["night_desk_lamp"]` | 0.45 | ask | Mock + 真后端 |
| `study_ask_ac` | single | `["study_ask_ac"]` | 0.88 | auto | Mock + 真后端 |
| `study_ask_light` | single | `["study_ask_light"]` | 0.62 | shadow | Mock + 真后端 |

> **说明**：当前所有归档均为单自动化归档（`automation_ids` 长度为 1）。`mode=multi` 归档的 `automation_ids` 将包含多个 id，置信度接口按 `automation_id` 分别返回各子自动化的置信度。

### 映射逻辑（前端实现）

1. **列表页** (`AutomationsListView`)：`GET /graphs` 返回 `automation_ids[]`，`GET /conf/_all` 返回全量置信度。前端以 `automation_id` 为键匹配，在列表项上显示置信度 badge。
2. **详情页** (`AutomationDetailView`)：`GET /graphs/{name}` 返回 IR，其中 `ir.id` 即 `automation_id`。如需显示置信度，调用 `GET /conf/{name}` 按 `automation_id` 过滤。
3. **Diff 页** (`VersionsView`)：`GET /diff?name=&old=&new=` 的 structured diff 中，`added_nodes`/`removed_nodes`/`added_edges`/`removed_edges` 各项均含 `automation_id` 字段，与归档名通过 `automation_ids[]` 关联。

### 类型定义对照

```typescript
// src/types/api.ts
interface GraphItem {
  name: string               // 归档名
  latest_version: number
  saved_at: string
  note: string
  mode: string               // restart | single | multi
  automation_ids: string[]   // 归档名 → 自动化 id 映射
}

interface ConfidenceItem {
  automation_id: string      // 与 GraphItem.automation_ids[] 中的 id 对应
  confidence: number
  band: 'auto' | 'shadow' | 'ask'
}
```

## dist/ 构建说明

> Round 2 更新：dist/ 由 AF 侧在完整环境构建，沙箱内因 esbuild spawn EPERM 无法复现 `npm run build`。

### 构建命令

```bash
npm install --registry=https://registry.npmjs.org/  # 避免淘宝镜像包不完整
npm run build   # vue-tsc -b && vite build → dist/
```

### dist/ 产物清单（22 个独立产物）

| 类别 | 文件数 | 说明 |
|------|--------|------|
| 入口 HTML | 1 | `dist/index.html`（引用主 JS + 主 CSS） |
| 路由 chunk JS | 9 | 9 个页面组件各 1 个 chunk |
| 路由 chunk CSS | 9 | 9 个页面样式各 1 个 chunk |
| 组件 chunk | 1 | `SafetyAlert`（被 FaultsView 引用） |
| 主 bundle JS | 2 | 主入口 + 次入口 |
| 主 CSS | 1 | 全局样式 |
| Vue helper | 1 | `_plugin-vue_export-helper` |

### 构建环境要求

- **Node.js** ≥ 18（Vite 6 要求）
- **npm registry**：必须使用 `registry.npmjs.org`（淘宝镜像 `npmmirror.com` 的 vue@3.5.42 缺少 `.d.ts` 文件，导致 vue-tsc 报 110+ 类型错误）
- **沙箱限制**：esbuild 加载 `vite.config.ts` 需 spawn 子进程（`stdio: 'pipe'`），沙箱禁止 named pipe → EPERM。`npm run build` 和 `npm run preview` 均需在非沙箱环境执行。

### 部署方式

```bash
# 方式一：静态服务器
npx serve dist              # → http://localhost:3000

# 方式二：复制 dist/ 到任意 Web 服务器
# Nginx: root /path/to/dist;
# Apache: DocumentRoot /path/to/dist
```

- dist/ 为纯静态产物，无需 Node 运行时。
- SPA 路由需配置 fallback 到 `index.html`（如 Nginx `try_files $uri $uri/ /index.html`）。
