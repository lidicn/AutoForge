## 2. 行为增量

- **新增能力**：
  - `GraphStore`：`{root}/{name}/v{n}.json` 归档 Graph 版本（自增 + `saved_at`/`note`），可回读任意版本并重建 Graph。
  - 置信度持久化：`dump_confidence`/`load_confidence` + `GraphStore.save_conf/load_conf`（G4 全内存 → 落盘）。
  - 实例快照可回放：`instance_record`/`restore_context`（沿用 `Instance.to_dict()` 可序列化红线）。
  - `find_node(graph, "automation_id:node_id")`：IR 已支持的可寻址补齐查询 API。
  - `forge diff <a> <b>`：节点/边/参数/元信息级差异 + 人类可读渲染。
  - `forge store save/log`：归档与历史查看。
- **对外契约（CLI）**：新增 `diff`、`store`（`save`/`log`）子命令；`--root` 默认 `.forge`。
- **无 IR Schema 改动**；无运行时主链路改动。

## 4. 已知风险 / 残留项

- [ ] `GraphStore` 为**文件级**存储，无并发锁（原型期单写者够用）；多进程/多写者需加锁或换 Sqlite（属 P1 跨进程话题）。
- [ ] `diff_graphs` 按 `node.raw` 字段级比对；对"字段顺序"不敏感（dict 比对），但**不改**语义等价性判断（如把 `params` 键重排视为相同，符合预期）。
- [ ] `restore_context` 只还原 `InstanceContext`（审计/检查用），不重建可运行的 `Instance`（活快照/定时器无法离线复原）；完整回放属后续话题。
- [ ] `.forge/` 默认落在工作目录；建议加入 `.gitignore`（待确认）。
