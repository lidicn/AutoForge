## 2. 行为增量（与上一版的差异）

**核心**：补齐「部署前人审」「设备分级保护」「凭据免重启」三块治理能力；另附令牌过期 fail-closed。

### 2.1 待批队列（执行/批准物理分离）

- 部署前写操作（`af_save`）**先入 `{root}/pending/<op_id>.json`**，人审（HTTP/CLI）后**回放 payload** 落盘；`PendingOp` 把「执行 payload」与「展示 summary/blast_radius」**同包落盘**，无二次渲染漂移。
- **MCP 面绝不注册 `af_approve`/`af_reject`**（agent 不能自批）——`TOOLS` 只含 `af_save`（进 pending）。
- **提交前置第一道闸**：`submit_pending` 对含 `ir` 的 payload 先跑静态扫描，坏 IR **fail-fast 拒绝**（不改坏自动化占坑）；`approve` 回放时 `save_graph` **再校验一次**（双保险）。
- per-agent 熔断默认 20（同 `submitted_by` 第 21 条抛 `ServiceError(400)`）。
- HTTP 端点 `/api/pending/{list,approve,reject}`（approve 仅在服务层）；CLI `forge pending`。

### 2.2 设备保护分级（注册表 + tier + 取最严）

- `entity_acl` 升级为**可热更新注册表** `DeviceGuardRegistry`：支持 `match={type: entity|domain|area, value}` + `tier`（0=必须人审 / 1=放行但审计）+ `perm`（tier-1 内 `rw`/`r` 细分）；命中多条**取最严**。
- **兼容旧 ACL**：`from_acl` 把 `-` → tier-0、`rw`/`r` → tier-1（旧式 `entity_acl=` 入参自动包装，零破坏）。
- **判定引擎真正接线**：`StaticScanner._check_entities` — 读/写命中 tier-0 → `ENTITY_GUARD_TIER0`（error）；tier-1 且 `r` 写 → `ENTITY_ACL_DENIED`（保留旧 rw/r 语义）。
- **热更新**：`DeviceGuardRegistry.from_file(path)` 从 `device_acl.json` 加载（规则数组 / 旧 ACL 对象 / `{"rules":[…]}` 三形态），改文件后重新加载即生效，无需重启。
- **真实写路径接线**：`af_service.load_device_guard(store)` 从 `{store.root}/device_acl.json` 自动加载，`build`/`save_graph`/`submit_pending` 三处静态扫描均注入守卫（HTTP `/api/build` 已传 `store`）——**MCP/HTTP 的 `af_save`、approve 回放与 build 预检都会真正执行 tier 分级**；文件缺失则 no-op（向后兼容）。CLI 侧新增 `forge build --guard`。

### 2.3 凭据热重载（`connection_revision` 代数）

- 凭据落 `{root}/credentials.json`（**gitignore + `0600`**，原子写），**绝不回明文**；`describe()` 只回掩码 + 长度（连末 4 位都不露）。
- 改凭据 → `bump_revision`（代数 +1，落盘 `revision.json`）→ `HATransport`/`HAEventStream` 比对代数变化即**丢弃缓存 token 重建**（同进程多 Runtime 自愈，免重启）。
- 文件优先、缺省回退 `AUTOFORGE_HA_TOKEN`（向后兼容原型期 `export` 启动）。
- `get_config(root)` 进程内单例（按 root 缓存），保证 `af_cli watch` 与适配器引用同一代数。

### 2.4 附 · 令牌过期三重 fail-closed（§2.8）

- `AUTOFORGE_TOKENS` 每条令牌可选 `expires_at`（ISO8601，**必须带时区**）。
- **无法解析** / **naive（无时区）** → 该令牌 **fail-closed 拒绝**（不是放过）；**已过期** → `TokenExpired`（HTTP 403）。
- 未配 `expires_at` → 永不过期（向后兼容）。

## 3. 验证方式

```powershell
# 全量
python -m pytest tests -q
# 本版单测（20 条）
python -m pytest tests/unit/test_v1_4_pending.py tests/unit/test_v1_4_device_guard.py `
                 tests/unit/test_v1_4_credentials.py tests/unit/test_v1_4_token_expiry.py -q
```

- **待批队列**：`submit_pending` 后 `{root}/pending/<op_id>.json` 存在；`list_pending` 可见；`approve_pending` 后 store 出现新版本且 pending 文件删除；同 `submitted_by` 第 21 条抛 `ServiceError`；`TOOLS` 不含 `af_approve`/`af_reject`。
- **设备分级**：`from_acl({"light.x":"-"})` → tier0；实体 + domain 双命中取最严 0；`StaticScanner` 注入 tier0 规则 → 报 `ENTITY_GUARD_TIER0`；改 `device_acl.json` 后 `from_file` 重新加载 → 拦截结果随之变化（热更新）。
- **凭据热重载**：`describe()` 掩码 `****len=N`（不含明文/末 4 位）；`update_credentials` → 代数 +1 且新实例读到持久化代数；`HATransport.call` 后 `token == "NEW"`；`get_config` 同一 root 返回同一实例。
- **令牌过期**：过期 → `TokenExpired`（HTTP 403，detail 含「过期」）；无法解析 / naive → `authenticate` 返回 `None`（HTTP 403）；`whoami` 对过期令牌 → 401；合法未来过期时间 → 放行（400 卡 IR 校验）。
