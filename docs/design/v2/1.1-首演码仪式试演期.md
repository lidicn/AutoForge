## 0 · 项目背景（目标仓现状）

新增独立模块 af_premiere：部署前一次性 6 位首演码绑定当前 store diff 的 SHA256（防验码后掉包）+ 5 分钟过期 + 原子消费防重放；部署落地后自动进入试演期（默认 24h），只统计不封禁，assert 失败/抖动自动暂停并推送。注意：AutoForge 模块耦合度高，本单只把 ir.schema.json 与 af_audit.py 作为接口面种子（避免闭包爆炸超 50,000 字符墙）；待挂接的 apply/diff/watch 钩子以「必须照做的形状」补在下方，MiMo 以正文为准。af_premiere 本身为独立新模块，依赖仅标准库。

**已知缺口（真机 vs 现状，按爆炸半径排序）**

| 缺口 | 现状 | 目标 |
|---|---|---|
| 一次性码 | `af_live` 仅二次确认+非空白名单三重闸，无一次性码/哈希绑定 | `af_premiere.issue(store_diff_sha256, ttl_s=300)` 发 6 位码并绑定哈希；`consume(code, store_diff_sha256)` 校验哈希一致 |
| 过期 | 无 | 码超 ttl_s（默认 300s=5min，可配）后 `consume` 拒绝 |
| 原子消费 | 无 | 同一码第二次 `consume` 拒绝（防重放）；消费动作加锁/标记原子 |
| 试演期 | 部署=终点 | 在 `af_pending.apply`（或 af_cli 部署入口）成功后调用 `af_premiere.enter_trial(store_diff_sha256, hours=24)`；试演期内 `af_live` watch 守护只统计不封禁；assert 失败/抖动触发 `af_premiere.pause_and_notify(pusher)`，`pusher` 为可注入回调（WebPush/HTTP），不执行真实封禁 |
| 审计 | `af_audit` 已有审计日志 | 首演码签发/消费/试演期暂停事件写入 `af_audit` |

```python
"""结构化审计 —— 供 G4 回灌 MA 与人工排障。

G1 记录四类必填事件（IR §9.4 的失败类型）加上总线/配额类系统事件：
- `entity_drift`  实体漂移（引用了不存在的实体）→ 走 on_error 软失效
- `action_failed` 适配器调用失败（设备异常 / 5xx）
- `breaker_open` / `breaker_recover`  实体变更频率熔断
- `quota_exceeded` 并发配额超限
"""

from __future__ import annotations

import json
from dataclasses import dataclass, field
from datetime import datetime, timezone
from pathlib import Path
from typing import Any, Iterator, Mapping

__all__ = ["AuditEvent", "AuditLog", "WRITE_CONFLICT", "record_conflict"]

ENTITY_DRIFT = "entity_drift"
ACTION_FAILED = "action_failed"
#: v0.3.0 跨自动化事件·发布侧（`emit` 发布的自定义事件）
EVENT_EMITTED = "event_emitted"
BREAKER_OPEN = "breaker_open"
BREAKER_RECOVER = "breaker_recover"
QUOTA_EXCEEDED = "quota_exceeded"
INSTANCE_REJECTED = "instance_rejected"
INSTANCE_EXPIRED = "instance_expired"
#: P1 实例持久化：崩溃恢复时成功挂回 / 因图变更被丢弃
INSTANCE_RESTORED = "instance_restored"
INSTANCE_RESTORE_DROPPED = "instance_restore_dropped"
#: v0.9.0 跨进程：写入版本冲突（expect_version 不匹配）与恢复时租约仍属其他进程
WRITE_CONFLICT = "write_conflict"
INSTANCE_LEASE_HELD = "instance_lease_held"

ALL_EVENT_TYPES = (
    ENTITY_DRIFT,
    ACTION_FAILED,
    EVENT_EMITTED,
    BREAKER_OPEN,
    BREAKER_RECOVER,
    QUOTA_EXCEEDED,
    INSTANCE_REJECTED,
    INSTANCE_EXPIRED,
    INSTANCE_RESTORED,
    INSTANCE_RESTORE_DROPPED,
    WRITE_CONFLICT,
    INSTANCE_LEASE_HELD,
)


@dataclass(frozen=True)
class AuditEvent:
    """一条审计记录。字段保持扁平可 JSON 化。"""

    type: str
    at: datetime
    message: str
    automation_id: str = ""
    instance_id: str = ""
    node_id: str = ""
    entity_id: str = ""
    data: dict[str, Any] = field(default_factory=dict)

    def to_dict(self) -> dict[str, Any]:
        return {
            "type": self.type,
            "at": self.at.isoformat(),
            "message": self.message,
            "automation_id": self.automation_id,
            "instance_id": self.instance_id,
            "node_id": self.node_id,
            "entity_id": self.entity_id,
            "data": dict(self.data),
        }


@dataclass
class AuditLog:
    """内存审计日志（G1 不落盘；结构保持不变，G2 可直接换持久化实现）。"""

    events: list[AuditEvent] = field(default_factory=list)

    def add(self, event: AuditEvent) -> AuditEvent:
        self.events.append(event)
        return event

    def of_type(self, *types: str) -> list[AuditEvent]:
        return [e for e in self.events if e.type in types]

    def __iter__(self) -> Iterator[AuditEvent]:
        return iter(self.events)

    def __len__(self) -> int:
        return len(self.events)

    def clear(self) -> None:
        self.events.clear()


def record_conflict(
    journal: str | Path,
    *,
    name: str,
    expected: int | None,
    actual: int | None,
    writer: str = "",
    note: str = "",
) -> dict[str, Any]:
    """把一条 `write_conflict` 追加进跨进程共享的 JSONL 冲突日志（可审计）。

    追加单行（O_APPEND 语义，单行 <4KB）在无锁并发下也不会撕裂；
    返回写入的条目（供测试/调用方断言）。
    """
    entry = {
        "type": WRITE_CONFLICT,
        "at": datetime.now(timezone.utc).isoformat(),
        "name": name,
        "expected_version": expected,
        "actual_version": actual,
        "writer": writer,
        "note": note,
    }
    path = Path(journal)
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("a", encoding="utf-8") as f:
        f.write(json.dumps(entry, ensure_ascii=False) + "\n")
    return entry
```

```python
    norm = _normalize_code(code)

    with self._lock:
```

```python
class Premiere:
    """首演码 + 试演期的会话状态机。可注入 clock/pusher/audit，方便时间旅行测试与假推送验证。"""

    def __init__(
        self,
        *,
        audit: Any = None,
        now: Clock | None = None,
        state_path: str | Path | None = None,
        default_pusher: Pusher | None = None,
        burn_on_mismatch: bool = False,
        retention_s: float = DEFAULT_RETENTION_S,
    ) -> None:
        self._audit = audit
        self._now: Clock = now or _utcnow
        self._state_path = Path(state_path) if state_path is not None else None
        self._default_pusher = default_pusher
        self._burn_on_mismatch = bool(burn_on_mismatch)
        self._retention_s = float(retention_s)
        self._lock = threading.RLock()
        self._codes: dict[str, CodeRecord] = {}
        self._trials: list[Trial] = []
        if self._state_path is not None and self._state_path.exists():
            self._load()

    # ---------- 状态持久化（可选） ----------
    def _load(self) -> None:
        assert self._state_path is not None
        try:
            raw = json.loads(self._state_path.read_text(encoding="utf-8"))
            codes = raw["codes"]
            trials = raw["trials"]
            if int(raw.get("version", 0)) != STATE_VERSION:
                raise ValueError("state version mismatch")
            self._codes = {d["fingerprint"]: CodeRecord.from_dict(d) for d in codes}
            self._trials = [Trial.from_dict(d) for d in trials]
        except Exception as exc:  # fail-closed：状态坏了必须让人看见
            raise RuntimeError(
                f"af_premiere 状态文件损坏或不可读：{self._state_path}（拒绝静默重建，避免重放窗口重开）"
            ) from exc

    def _save(self) -> None:
        if self._state_path is None:
            return
        payload = {
            "version": STATE_VERSION,
            "codes": [rec.to_dict() for rec in self._codes.values()],
            "trials": [t.to_dict() for t in self._trials],
        }
        self._state_path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self._state_path.with_name(f"{self._state_path.name}.{os.getpid()}.tmp")
        tmp.write_text(json.dumps(payload, ensure_ascii=False, indent=2), encoding="utf-8")
        os.replace(tmp, self._state_path)
```

```python
                    fingerprint=fp, store_diff_sha256=sha,
                    issued_at=now, expires_at=now + timedelta(seconds=ttl), ttl_s=ttl,

                self._codes[fp] = rec

                    "ttl_s": ttl, "issued_at": rec.issued_at.isoformat(),
                    "expires_at": rec.expires_at.isoformat(),
                })
                self._save()
                return code
        raise RuntimeError("无法签发唯一首演码（随机源异常或号段耗尽）")
```

```python
"""af_pending —— 待落地 store diff 的暂存与一次性 apply（首演码仪式的落地面）。

必须照做的挂接形状（apply / diff 钩子，watch 钩子见 af_premiere 顶部）：
- `diff_sha256(text) -> str`  ：与 af_premiere 同一摘要（sha256 hex），验码与落地共用一把尺
- `stage(text) -> PendingChange` / `stage_file(path) -> PendingChange`
- `apply(change, code, *, premiere=None, target=None, hours=24.0, audit=None) -> Result`
    顺序固定：consume 首演码（校验摘要一致）→ 原子落地（os.replace）→ enter_trial
    任一步失败即 fail-closed 返回，不静默继续。
"""

import json
import os
from dataclasses import dataclass
from datetime import datetime, timezone
from pathlib import Path
from typing import Any

try:
    from . import af_premiere
    from .af_audit import AuditEvent, AuditLog
    from .af_premiere import DEFAULT_TRIAL_HOURS, Result, sha256_hex
except ImportError:  # pragma: no cover
    import af_premiere
    from af_audit import AuditEvent, AuditLog
    from af_premiere import DEFAULT_TRIAL_HOURS, Result, sha256_hex

__all__ = ["PendingChange", "stage", "stage_file", "diff_sha256", "apply", "atomic_write",
           "PREMIERE_APPLY_COMMITTED", "PREMIERE_APPLY_FAILED"]

PREMIERE_APPLY_COMMITTED = "premiere_apply_committed"
PREMIERE_APPLY_FAILED = "premiere_apply_failed"


def diff_sha256(text: str) -> str:
    return sha256_hex(text)


@dataclass(frozen=True)
class PendingChange:
    text: str
    sha256: str
    staged_at: datetime

    def to_dict(self) -> dict[str, Any]:
        return {"sha256": self.sha256, "staged_at": self.staged_at.isoformat(), "bytes": len(self.text.encode("utf-8"))}


def stage(text: str, *, now: datetime | None = None) -> PendingChange:
    if not isinstance(text, str):
        raise TypeError("text 必须是 str")
    return PendingChange(text=text, sha256=diff_sha256(text), staged_at=now or datetime.now(timezone.utc))


def stage_file(path: str | Path, *, now: datetime | None = None) -> PendingChange:
    return stage(Path(path).read_text(encoding="utf-8"), now=now)


def atomic_write(path: str | Path, text: str) -> Path:
    p = Path(path)
    p.parent.mkdir(parents=True, exist_ok=True)
    tmp = p.with_name(f"{p.name}.{os.getpid()}.tmp")
    tmp.write_text(text, encoding="utf-8")
    os.replace(tmp, p)
    return p


def _emit(audit, type_: str, message: str, data: dict[str, Any]) -> None:
    if audit is None:
        return
    audit.add(AuditEvent(type=type_, at=datetime.now(timezone.utc), message=message, data=dict(data)))


def apply(change, code, *, premiere=None, target=None, hours=DEFAULT_TRIAL_HOURS, audit=None) -> Result:
    if not isinstance(change, PendingChange):
        raise TypeError("change 必须是 PendingChange")
    gate = premiere if premiere is not None else af_premiere.get_default()
    consumed = gate.consume(code, change.sha256)
    if not consumed:
        return Result(ok=False, stage="consume", reason=consumed.get("reason", "rejected"), sha256=change.sha256)
    target_s = str(target) if target is not None else ""
    if target is not None:
        try:
            atomic_write(target, change.text)
        except OSError as exc:
            _emit(audit, PREMIERE_APPLY_FAILED, "落地写盘失败（首演码已消费，需重新签发）",
                  {"sha256": change.sha256, "target": target_s, "error": f"{type(exc).__name__}: {exc}"})
            return Result(ok=False, stage="commit", reason="io_error", sha256=change.sha256, target=target_s, error=f"{type(exc).__name__}: {exc}")
    trial = gate.enter_trial(change.sha256, hours=hours)
    _emit(audit, PREMIERE_APPLY_COMMITTED, "store diff 已落地，进入试演期",
          {"sha256": change.sha256, "target": target_s, "trial_id": (trial.get("trial") or {}).get("trial_id", "")})
    return Result(ok=True, stage="applied", sha256=change.sha256, target=target_s, trial=trial.get("trial"))
```

## 1 · 设计概览（三段仪式 + 三个只读钩子）

```
部署前                    部署时                     部署后
issue(sha256, ttl=300) → consume(code, sha256)   → enter_trial(sha256, hours=24)
  6 位码·绑 diff 摘要       原子消费·防重放·防掉包        试演期：只统计不封禁
```

```python
        except Exception as exc:  # fail-closed：状态坏了必须让人看见，不静默重建
            raise RuntimeError(
                f"af_premiere 状态文件损坏或不可读：{self._state_path}"
                "（拒绝静默重建，避免重放窗口重开）"
            ) from exc

    def _save(self) -> None:
        if self._state_path is None:
            return
        payload = {
            "version": STATE_VERSION,
            "codes": [rec.to_dict() for rec in self._codes.values()],
            "trials": [t.to_dict() for t in self._trials],
        }
        self._state_path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self._state_path.with_name(f"{self._state_path.name}.{os.getpid()}.tmp")
        tmp.write_text(json.dumps(payload, ensure_ascii=False, indent=2), encoding="utf-8")
        os.replace(tmp, self._state_path)  # 原子替换，不留 tmp 残渣

    # ---------- 审计（不改 af_audit.py，直接产 AuditEvent） ----------
    def _emit(self, type_: str, message: str, data: dict[str, Any]) -> None:
        if self._audit is None:
            return
        self._audit.add(AuditEvent(type=type_, at=self._now(), message=message, data=dict(data)))

    # ---------- 内部维护 ----------
    def _purge(self, now: datetime) -> None:
        keep: dict[str, CodeRecord] = {}
        for fp, rec in self._codes.items():
            dead = rec.consumed_at or rec.expires_at
            if dead is not None and (now - dead).total_seconds() > self._retention_s:
                continue
            keep[fp] = rec
        self._codes = keep
        self._trials = [t for t in self._trials if (now - t.ends_at).total_seconds() <= self._retention_s]

    def _active_trial(self, sha: "str | None", now: datetime) -> "Trial | None":
        hit: "Trial | None" = None
        for t in self._trials:
            if sha is not None and t.store_diff_sha256 != sha:
                continue
            if t.running(now) and (hit is None or t.started_at >= hit.started_at):
                hit = t
        return hit

    # ---------- 1) 签发 ----------
    def issue(self, store_diff_sha256: str, ttl_s: float = DEFAULT_TTL_S) -> str:
        """签发一次性 6 位首演码并绑定 store diff 摘要；明文码只在此刻可见一次。"""
        sha = _normalize_sha(store_diff_sha256)
        ttl = _positive(ttl_s, "ttl_s")
        with self._lock:
            now = self._now()
            self._purge(now)
            for _ in range(64):
                code = f"{secrets.randbelow(10 ** CODE_LENGTH):0{CODE_LENGTH}d}"
                fp = code_fingerprint(code)
                if fp in self._codes:
                    continue  # 留存期内的指纹不复用
                rec = CodeRecord(
                    fingerprint=fp,
                    store_diff_sha256=sha,
                    issued_at=now,
                    expires_at=now + timedelta(seconds=ttl),
                    ttl_s=ttl,
                )
                self._codes[fp] = rec
                self._emit(PREMIERE_CODE_ISSUED, "首演码已签发", {
                    "code_fingerprint": fp, "store_diff_sha256": sha, "ttl_s": ttl,
                    "issued_at": rec.issued_at.isoformat(), "expires_at": rec.expires_at.isoformat(),
                })
                self._save()
                return code
        raise RuntimeError("无法签发唯一首演码（随机源异常或号段耗尽）")

    # ---------- 2) 原子消费 ----------
    def consume(self, code: Any, store_diff_sha256: str) -> Result:
        sha = _normalize_sha(store_diff_sha256)
        norm = _normalize_code(code)
        with self._lock:  # 检查 + 标记同一临界区 → 原子防重放
            now = self._now()
            if norm is None:
                return self._reject("", sha, "malformed_code", now)
            fp = code_fingerprint(norm)
            rec = self._codes.get(fp)
            if rec is None:
                return self._reject(fp, sha, "unknown_code", now)
            rec.attempts += 1
            if rec.consumed:
                return self._reject(fp, sha, "already_consumed", now, rec=rec)
            if rec.is_expired(now):
                return self._reject(fp, sha, "expired", now, rec=rec)
            if rec.store_diff_sha256 != sha:
                if self._burn_on_mismatch:
                    rec.consumed_at = now
                self._save()
                return self._reject(fp, sha, "hash_mismatch", now, rec=rec, burned=self._burn_on_mismatch)
            rec.consumed_at = now
            self._emit(PREMIERE_CODE_CONSUMED, "首演码已消费", {
                "ok": True, "reason": "ok", "code_fingerprint": fp,
                "store_diff_sha256": sha, "consumed_at": rec.consumed_at.isoformat(),
                "expires_at": rec.expires_at.isoformat(), "attempts": rec.attempts,
            })
            self._save()
            return Result(
                ok=True, reason="ok", code_fingerprint=fp, store_diff_sha256=sha,
                consumed_at=rec.consumed_at.isoformat(), expires_at=rec.expires_at.isoformat(),
                attempts=rec.attempts,
            )

    def _reject(self, fp: str, sha: str, reason: str, now: datetime, *,
                rec: "CodeRecord | None" = None, burned: bool = False) -> Result:
        self._emit(PREMIERE_CODE_CONSUMED, "首演码消费被拒", {
            "ok": False, "reason": reason, "code_fingerprint": fp,
            "store_diff_sha256": sha, "at": now.isoformat(),
            "attempts": rec.attempts if rec else 0, "burned": burned,
        })
        return Result(ok=False, reason=reason, code_fingerprint=fp,
                      store_diff_sha256=sha, burned=burned)

    # ---------- 3) 试演期 ----------
    def enter_trial(self, store_diff_sha256: str, hours: float = DEFAULT_TRIAL_HOURS) -> Result:
        sha = _normalize_sha(store_diff_sha256)
        h = _positive(hours, "hours")
        with self._lock:
            now = self._now()
            self._purge(now)
            trial = Trial(
                trial_id=uuid.uuid4().hex[:12], store_diff_sha256=sha,
                started_at=now, ends_at=now + timedelta(hours=h), hours=h,
            )
            self._trials.append(trial)
            payload = trial.to_dict()
            self._emit(PREMIERE_TRIAL_ENTERED, "部署落地，已进入试演期（只统计不封禁）", payload)
            self._save()
        return Result(ok=True, reason="ok", trial=payload)

    def active_trial(self, store_diff_sha256: "str | None" = None) -> "Trial | None":
        sha = _normalize_sha(store_diff_sha256) if store_diff_sha256 is not None else None
        with self._lock:
            return self._active_trial(sha, self._now())

    def trial_status(self, store_diff_sha256: "str | None" = None) -> "dict[str, Any] | None":
        with self._lock:
            now = self._now()
            sha = _normalize_sha(store_diff_sha256) if store_diff_sha256 is not None else None
            trial = self._active_trial(sha, now)
            if trial is None:
                cands = [t for t in self._trials if sha is None or t.store_diff_sha256 == sha]
                if not cands:
                    return None
                trial = max(cands, key=lambda t: t.started_at)
            d = trial.to_dict()
            d["running"] = trial.running(now)
            return d

    def mode(self, store_diff_sha256: "str | None" = None) -> str:
        """observe=试演期（只统计不封禁）；enforce=正常执行既有策略。"""
        return "observe" if self.active_trial(store_diff_sha256) is not None else "enforce"

    def should_ban(self, store_diff_sha256: "str | None" = None) -> bool:
        """af_premiere 自己永不封禁；只回答「既有封禁策略此刻是否放行」。"""
        return self.mode(store_diff_sha256) == "enforce"

    def observe(self, kind: str, *, automation_id: str = "", entity_id: str = "",
                message: str = "", ban_sink: "BanSink | None" = None, **extra: Any) -> Result:
        """watch 守护上报一次观察。试演期只统计；非试演期才交给既有封禁策略。"""
        meta: dict[str, Any] = {"kind": kind, "automation_id": automation_id,
                                "entity_id": entity_id, "message": message}
        meta.update(extra)
        with self._lock:
            trial = self._active_trial(None, self._now())
            if trial is not None:
                trial.bump(kind)
                self._save()
                return Result(ok=True, reason="count_only", action="count_only", banned=False,
                              trial_id=trial.trial_id, counters=dict(trial.counters), detail=meta)
        if ban_sink is not None:  # 试演期外：策略交还给既有封禁实现（本模块不下发任何动作）
            ban_sink(kind, meta)
        return Result(ok=True, reason="enforce", action="ban", banned=ban_sink is not None, detail=meta)

    def on_assert_failure(self, *, pusher: "Pusher | None" = None, automation_id: str = "",
                          message: str = "", **extra: Any) -> Result:
        return self._on_signal("assert_failure", pusher, automation_id=automation_id,
                               message=message, **extra)

    def on_jitter(self, *, pusher: "Pusher | None" = None, entity_id: str = "",
                  message: str = "", **extra: Any) -> Result:
        return self._on_signal("jitter", pusher, entity_id=entity_id, message=message, **extra)

    def _on_signal(self, kind: str, pusher: "Pusher | None", **meta: Any) -> Result:
        with self._lock:
            now = self._now()
            trial = self._active_trial(None, now)
            if trial is None:
                return Result(ok=False, reason="no_active_trial", signal=kind)
            trial.bump(kind)
            self._save()
        detail: dict[str, Any] = {"signal": kind}
        detail.update({k: v for k, v in meta.items() if v not in ("", None)})
        return self.pause_and_notify(pusher, reason=kind, meta=detail)

    def pause_and_notify(self, pusher: "Pusher | None" = None, *, reason: str = "",
                         force: bool = False, meta: "dict[str, Any] | None" = None) -> Result:
        """试演期自动暂停并推送（可注入 pusher）。绝不执行任何真实封禁。"""
        with self._lock:
            now = self._now()
            trial = self._active_trial(None, now)
            if trial is None:
                return Result(ok=False, reason="no_active_trial")
            if trial.state == "paused" and not force:
                return Result(ok=False, reason="already_paused",
                              trial_id=trial.trial_id, notified=False)  # 防推送风暴
            trial.state = "paused"
            trial.pause_reason = reason or "manual"
            trial.paused_at = now
            payload = {
                "type": PREMIERE_TRIAL_PAUSED, "at": now.isoformat(),
                "trial_id": trial.trial_id, "store_diff_sha256": trial.store_diff_sha256,
                "reason": trial.pause_reason, "counters": dict(trial.counters),
                "detail": dict(meta or {}),
                "note": "试演期自动暂停：只统计不封禁，等待人工确认",
            }
            self._emit(PREMIERE_TRIAL_PAUSED, "试演期已暂停并推送", payload)
            self._save()
        sink = pusher if pusher is not None else self._default_pusher
        notified, err = self._deliver(sink, payload)
        out = Result(ok=True, reason="paused", trial_id=payload["trial_id"],
                     notified=notified, payload=payload)
        if err:
            out["push_error"] = err
        return out

    @staticmethod
    def _deliver(pusher: "Pusher | None", payload: dict[str, Any]) -> "tuple[bool, str]":
        if pusher is None:
            return False, ""
        try:
            pusher(payload)
            return True, ""
        except Exception as exc:  # 推送 fail-open；暂停状态 fail-closed
            return False, f"{type(exc).__name__}: {exc}"

    def end_trial(self, store_diff_sha256: "str | None" = None) -> Result:
        with self._lock:
            sha = _normalize_sha(store_diff_sha256) if store_diff_sha256 is not None else None
            trial = self._active_trial(sha, self._now())
            if trial is None:
                return Result(ok=False, reason="no_active_trial")
            trial.state = "ended"
            self._save()
            return Result(ok=True, reason="ended", trial=trial.to_dict())

    def describe(self, code: Any) -> "dict[str, Any] | None":
        norm = _normalize_code(code)
        if norm is None:
            return None
        with self._lock:
            rec = self._codes.get(code_fingerprint(norm))
            return rec.to_dict() if rec else None


# ---------- 模块级默认实例 + 契约函数（af_premiere.issue / consume / enter_trial ...） ----------
```

## 3 · `src/autoforge/af_pending.py`

```python
"""af_pending —— 待落地 store diff 的暂存与一次性 apply（首演码仪式的落地面）。

必须照做的挂接形状（apply / diff 钩子；watch 侧三个只读钩子见 af_premiere 模块头）：
- `diff_sha256(text) -> str`                       与 af_premiere 同一把尺（sha256 hex）
- `stage(text) -> PendingChange` / `stage_file(path) -> PendingChange`
- `apply(change, code, *, premiere=None, target=None, hours=24.0, audit=None) -> Result`
    顺序固定：consume 首演码（校验摘要一致）→ 原子落地（os.replace）→ enter_trial
    任一步失败即 fail-closed 返回，不静默继续。
"""

from __future__ import annotations

import os
from dataclasses import dataclass
from datetime import datetime, timezone
from pathlib import Path
from typing import Any

try:
    from . import af_premiere
    from .af_audit import AuditEvent
    from .af_premiere import DEFAULT_TRIAL_HOURS, Result, sha256_hex
except ImportError:  # pragma: no cover
    import af_premiere
    from af_audit import AuditEvent
    from af_premiere import DEFAULT_TRIAL_HOURS, Result, sha256_hex

__all__ = ["PendingChange", "stage", "stage_file", "diff_sha256", "apply",
           "atomic_write", "PREMIERE_APPLY_COMMITTED", "PREMIERE_APPLY_FAILED"]

PREMIERE_APPLY_COMMITTED = "premiere_apply_committed"
PREMIERE_APPLY_FAILED = "premiere_apply_failed"


def diff_sha256(text: str) -> str:
    return sha256_hex(text)


@dataclass(frozen=True)
class PendingChange:
    text: str
    sha256: str
    staged_at: datetime

    def to_dict(self) -> dict[str, Any]:
        return {"sha256": self.sha256, "staged_at": self.staged_at.isoformat(),
                "bytes": len(self.text.encode("utf-8"))}


def stage(text: str, *, now: "datetime | None" = None) -> PendingChange:
    if not isinstance(text, str):
        raise TypeError("text 必须是 str")
    return PendingChange(text=text, sha256=diff_sha256(text),
                         staged_at=now or datetime.now(timezone.utc))


def stage_file(path: "str | Path", *, now: "datetime | None" = None) -> PendingChange:
    return stage(Path(path).read_text(encoding="utf-8"), now=now)


def atomic_write(path: "str | Path", text: str) -> Path:
    p = Path(path)
    p.parent.mkdir(parents=True, exist_ok=True)
    tmp = p.with_name(f"{p.name}.{os.getpid()}.tmp")
    tmp.write_text(text, encoding="utf-8")
    os.replace(tmp, p)
    return p


def _emit(audit: Any, type_: str, message: str, data: dict[str, Any]) -> None:
    if audit is None:
        return
    audit.add(AuditEvent(type=type_, at=datetime.now(timezone.utc), message=message, data=dict(data)))


def apply(change: PendingChange, code: Any, *, premiere: Any = None,
          target: "str | Path | None" = None, hours: float = DEFAULT_TRIAL_HOURS,
          audit: Any = None) -> Result:
    if not isinstance(change, PendingChange):
        raise TypeError("change 必须是 PendingChange")
    gate = premiere if premiere is not None else af_premiere.get_default()
    consumed = gate.consume(code, change.sha256)  # 摘要不一致 / 过期 / 重放 → 拒绝
    if not consumed:
        return Result(ok=False, stage="consume",
                      reason=consumed.get("reason", "rejected"), sha256=change.sha256)
    target_s = str(target) if target is not None else ""
    if target is not None:
        try:
            atomic_write(target, change.text)
        except OSError as exc:  # 码已消费不回滚：一码 = 一次落地尝试，失败需重新签发
            err = f"{type(exc).__name__}: {exc}"
            _emit(audit, PREMIERE_APPLY_FAILED,
                  "落地写盘失败（首演码已消费，需重新签发）",
                  {"sha256": change.sha256, "target": target_s, "error": err})
            return Result(ok=False, stage="commit", reason="io_error",
                          sha256=change.sha256, target=target_s, error=err)
    trial = gate.enter_trial(change.sha256, hours=hours)
    _emit(audit, PREMIERE_APPLY_COMMITTED, "store diff 已落地，进入试演期",
          {"sha256": change.sha256, "target": target_s,
           "trial_id": (trial.get("trial") or {}).get("trial_id", "")})
    return Result(ok=True, stage="applied", sha256=change.sha256,
                  target=target_s, trial=trial.get("trial"))
```

## 4 · `src/autoforge/af_cli.py`

```python
"""af_cli —— 首演码仪式的运维入口（argparse，仅标准库）。

示例：
    python -m autoforge.af_cli sha     --diff-file store.diff
    python -m autoforge.af_cli issue   --diff-file store.diff --ttl 300
    python -m autoforge.af_cli consume --code 123456 --diff-file store.diff
    python -m autoforge.af_cli apply   --code 123456 --diff-file store.diff --target live.json --hours 24
    python -m autoforge.af_cli status

每个子命令都可带：
    --state PATH   仪式状态文件（默认 $AUTOFORGE_PREMIERE_STATE 或 ./.autoforge/premiere_state.json）
    --no-state     纯内存模式
    --audit PATH   把本次仪式的 af_audit 事件追加成 JSONL
输出一律 JSON；退出码 0=成功 / 1=被拒 / 2=用法错误。
"""

from __future__ import annotations

import argparse
import json
import os
import sys
from pathlib import Path
from typing import Any, Sequence

try:
    from . import af_pending, af_premiere
    from .af_premiere import AuditLog
except ImportError:  # pragma: no cover
    import af_pending
    import af_premiere
    from af_premiere import AuditLog

DEFAULT_STATE = ".autoforge/premiere_state.json"


def _state_path(args: Any) -> "str | None":
    if args.no_state:
        return None
    return args.state or os.environ.get("AUTOFORGE_PREMIERE_STATE") or DEFAULT_STATE


def _dump(payload: Any) -> None:
    print(json.dumps(payload, ensure_ascii=False, indent=2, default=str))


def _append_audit(path: str, audit: AuditLog) -> None:
    p = Path(path)
    p.parent.mkdir(parents=True, exist_ok=True)
    with p.open("a", encoding="utf-8") as f:
        for e in audit:
            f.write(json.dumps(e.to_dict(), ensure_ascii=False) + "\n")


def _build_parser() -> argparse.ArgumentParser:
    common = argparse.ArgumentParser(add_help=False)
    common.add_argument("--state", default=None, help="仪式状态文件路径")
    common.add_argument("--no-state", action="store_true", help="纯内存模式（不落状态文件）")
    common.add_argument("--audit", default=None, help="审计 JSONL 追加路径")

    p = argparse.ArgumentParser(prog="af_cli", description="AutoForge 首演码仪式 CLI")
    sub = p.add_subparsers(dest="cmd", required=True)

    s = sub.add_parser("sha", parents=[common], help="计算 store diff 摘要")
    s.add_argument("--diff-file", required=True)

    s = sub.add_parser("issue", parents=[common], help="签发一次性 6 位首演码")
    s.add_argument("--diff-file", required=True)
    s.add_argument("--ttl", type=float, default=af_premiere.DEFAULT_TTL_S)

    s = sub.add_parser("consume", parents=[common], help="消费首演码（校验摘要一致）")
    s.add_argument("--code", required=True)
    s.add_argument("--diff-file", required=True)

    s = sub.add_parser("apply", parents=[common], help="消费码 → 原子落地 → 进入试演期")
    s.add_argument("--code", required=True)
    s.add_argument("--diff-file", required=True)
    s.add_argument("--target", default=None, help="落地目标文件（原子写）")
    s.add_argument("--hours", type=float, default=af_premiere.DEFAULT_TRIAL_HOURS)

    sub.add_parser("status", parents=[common], help="查看试演期状态与放行模式")
    return p


def main(argv: "Sequence[str] | None" = None) -> int:
    args = _build_parser().parse_args(argv)
    audit = AuditLog()
    gate = af_premiere.Premiere(audit=audit, state_path=_state_path(args))
    rc = 0

    if args.cmd == "sha":
        payload = af_pending.stage_file(args.diff_file).to_dict()
    elif args.cmd == "issue":
        change = af_pending.stage_file(args.diff_file)
        code = gate.issue(change.sha256, ttl_s=args.ttl)
        payload = {"code": code, "store_diff_sha256": change.sha256,
                   "ttl_s": args.ttl, "describe": gate.describe(code)}
    elif args.cmd == "consume":
        change = af_pending.stage_file(args.diff_file)
        payload = gate.consume(args.code, change.sha256)
        rc = 0 if payload["ok"] else 1
    elif args.cmd == "apply":
        change = af_pending.stage_file(args.diff_file)
        payload = af_pending.apply(change, args.code, premiere=gate, target=args.target,
                                   hours=args.hours, audit=audit)
        rc = 0 if payload["ok"] else 1
    else:  # status
        payload = {"mode": gate.mode(), "should_ban": gate.should_ban(),
                   "trial": gate.trial_status()}

    _dump(payload)
    if args.audit:
        _append_audit(args.audit, audit)
    return rc


if __name__ == "__main__":
    raise SystemExit(main())
```

## 8 · 关键设计决策

1. **数据结构与索引**：`_codes: dict[指纹, CodeRecord]`（O(1) 消费）+ `_trials: list[Trial]`（试演期数量极少，线性取「覆盖当前时刻的最新一条」）。索引键是 `sha256(code)[:16]` 指纹——**明文码不进内存索引键、不进审计、不进状态文件**，只在 `issue()` 返回值里出现一次。
2. **原子消费**：`threading.RLock` 把「查表 + 标记 consumed_at」放进同一临界区（单测用 8 线程 Barrier 验证恰好一个赢家）。跨进程原子性见 §9 未决 3。
3. **失败/降级语义**：
   - 坏码/未知码/过期/已消费/摘要不一致 → 一律 **fail-closed 拒绝**，返回 `Result(ok=False, reason=...)` 不抛异常（守护进程可安全消费）。
   - 参数非法（摘要非 64 hex、ttl≤0、hours≤0）→ 程序员错误，**抛 ValueError**（fail-fast）。
   - pusher 抛异常 → 推送 **fail-open**（吞异常、`notified=False`、`push_error` 记录），但暂停状态 **fail-closed** 落地。
   - 状态文件损坏 → 抛 `RuntimeError`，**不静默重建**（否则重放窗口重开）。
   - 落地写盘失败 → fail-closed：码不回滚（**一码 = 一次落地尝试**，防同码二次落地），返回 `stage="commit"`，运维重新签发；`PREMIERE_APPLY_FAILED` 入审计。
4. **摘要不一致是否烧码**：默认不烧（`burn_on_mismatch=False`，可开）。理由：误填/重算 diff 是常见人为失误，烧码会把仪式变死锁；防掉包由「摘要绑定 + 5 分钟 TTL + 单次消费」承担。安全侧若要求更严，开开关即可（已有单测覆盖两种语义）。
5. **与现有实现的兼容边界**：`af_audit.py` **零改动**，用 `AuditEvent(type="premiere_*")` 写入注入的 `AuditLog`（duck typing `.add`）；`af_live.py` **零改动**，只留 `mode()/observe()/on_assert_failure()` 三个只读钩子；`ir.schema.json` 与首演码无关，未触碰。新增事件类型：`premiere_code_issued` / `premiere_code_consumed`（含拒绝原因）/ `premiere_trial_entered` / `premiere_trial_paused`，另有 af_pending 的 `premiere_apply_committed|failed`。
6. **`Result` 是 dict 子类**，`__bool__ = bool(self["ok"])`：兼容 `result["ok"] is True`、`if result:`、`assert result` 三种判读。
7. **码格式**：6 位纯数字（`secrets.randbelow(10**6)` 补零），指纹冲突即重抽（最多 64 次）。不做易混字符集——这是给人读/口播的仪式码，可用性优先于熵密度；暴力枚举风险见 §9 未决 4。
8. **`af_pending.apply` 顺序固定 consume → 原子写 → enter_trial**：先锁「一码一次落地」，避免同码二次落地；进试演期永远在落地之后，不会出现「试演期已开但没落地」。
9. **CLI 需要跨进程**，故 `--state` 走 JSON 状态文件（`os.replace` 原子替换、无 tmp 残渣，默认 `AUTOFORGE_PREMIERE_STATE` 或 `./.autoforge/premiere_state.json`）；**模块 API 默认纯内存**，与验收条目逐条对齐。

## 9 · 需求里说不清的地方（不猜，逐条列出）

1. **「自动暂停」到底暂停什么**：试演期看护本身 / 部署的自动化集合（等价停用或回滚）/ 只是升级告警？我实现为「trial.state=paused：停止自动动作、继续只统计不封禁、推送等人工确认」。若语义是「暂停自动化集合」，需要 af_pending 暴露 hold/release 钩子——本单没有该契约。
2. **「抖动」判据未给**：我只提供 `on_jitter()` 上报钩子，抖动检测（N 次翻转 / M 秒）在 watch 侧算好后上报；阈值归谁定？
3. **跨进程原子消费**：是否需要文件锁？现状是「单写者假设 + 原子替换」，Windows/POSIX 锁语义不同，加锁要先定平台口径。
4. **失败次数熔断**：6 位码 5 分钟窗口内可枚举（1e6），是否要「错 N 次烧码」？现只累计 `attempts` 并入审计，不封。
5. **试演期是全局单例还是每 sha 一条**：现为「每 sha 一条，取覆盖当前时刻的最新一条」。
6. **store 落地格式**：本单只知道 diff 文本，落地即「原子写整份 diff 到 `target`」；若真实 apply 是结构化 merge，替换 `af_pending.atomic_write` 一节即可。
7. **`af_pending` / `af_cli` 的接口形状**：正文只给了文件名与「apply 成功后进试演期」，具体签名由我按最小可用定义（`stage/stage_file/diff_sha256/apply` + argparse 子命令），若已有既定契约请回填，我按契约改。
8. **`tests/unit/test_af_premiere.py` 被列为「现有测试面」但模块尚不存在**：我按「本单交付即该文件全部内容」处理；若已有骨架，按测试方法名合并即可（全部是 `unittest.TestCase` 类方法，无 pytest fixture，冲突面最小）。
