## 5. 关键坑点速查（综合，必读）

### memory-agent 专属
1. **embedding/LLM 上游 401/503 误判**：根因是 new-api token 失效（非上游故障）。chroma 报错会二次包装成 `HTTPStatusError(__init__() missing request/response)`（httpx 版本不兼容混淆）。修复：MA `config.json` 的 `embedding_api_key` **与** `llm_backends` 中 new-api 后端的 `api_key` 同步改为 new-api tokens 表的值（id=5，key 明文存 `/data/one-api.db`，`docker cp new-api:/data/one-api.db` + sqlite3 读）。new-api 对 `Bearer <key>` 与 `Bearer sk-<key>` 都接受。
2. **FTS 中文不命中**：tokenizer 必须用 **trigram**（unicode61 把连续汉字当单 token）；trigram 要求 query≥3 字符。
3. **洗澡 19h 假阳性**：卫生间无水流传感器，真实用水证据=增压泵电源功率 ≥50W（待机~1W/运行~170-213W）；<3min 过滤马桶冲水。
4. **HDMI3 漂移失效**：`logical_id` 拼写 lidcn→lidicn；身份层去 `domain__` 前缀后可按人类友好名匹配合并设备。
5. **go2rtc 流 404**：config 流名缺 `cam_` 前缀（客厅→cam_客厅 等）；改 `go2rtc.yaml` 而非代码。
6. **process 挖掘 5 个口径坑**（全是聚合层）：秒级桶→10min 桶、伪房间 skip、遥测吃满分页→排除 TELEMETRY_DOMAINS、`min_cases_per_room` 样本不足跳过、**DFG 必须按房间算**（全局口径 50% 误报）。
7. **在线异常 HST 饱和**：HST 分数饱和无区分度，降级为 relative_top 参考；主判据=同小时中位数/MAD + `min_delta=10` 绝对下限（否则起夜刷屏）。ADWIN 漂移读 `drift_detected` **属性**（非返回值）。
8. **insert_perception_event 幂等**：`cur.rowcount` 不可靠（容器内"已写返回 0"）→ 用 `conn.total_changes` 差值。
9. **PIR 去抖 / 跨午夜时间窗**：事件表列为 `old_state/new_state`（无 `state` 列），引擎须 `e["state"]=e.get("new_state")`；`_iter_all_events` 用 `max_rows=` 非 `limit=`（否则重复 limit TypeError 被 except 吞）。
10. **MCP 跨版本字段名**：mcp 1.x `isError` / 2.x `is_error`，pydantic 静默忽略未知字段 → 检测/构造须 `getattr(r,"isError",False) or getattr(r,"is_error",False)` 动态适配。streamable HTTP 需 Accept 同时含 `application/json` + `text/event-stream`（否则 406）。
11. **结果缓存 key 抖动**：`days` 语义窗口终点=now 逐秒变 → 按分钟对齐 key（`start_iso[:16]`）才命中。

### 通用部署
12. **e:/NAS / E:/NAS 是断开副本**：改代码不会同步 NAS，必须 scp + restart/build。net use 报 "network connection could not be found"。
13. **docker restart 慢启动**：MA ~7min、AutoForge ~90s，过早验证 ConnectionRefused。
14. **新-api token 重置**会同时废掉 MA embedding 与 LLM → 二者需同步更新。
