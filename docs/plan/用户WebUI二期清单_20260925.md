# 用户 WebUI（ForgeSight）二期清单

> 日期：2026-09-25　决策人：用户（CB）
> 本文记录「手机用户端」**推迟到二期**的功能，以及一期已确认可用的范围。
> 主线切换到 AF 测试通道控制台 + v1.10.0 投产收口后，二期再动。

---

## 一、一期已可用（本轮确认，不必再投入）

现已对接完毕、手机上实际能用的能力：

| 能力 | 说明 |
|---|---|
| 配对弹窗 | agent 一发起请求，手机就弹 6 位码（EventSource 连 `/api/mcp/pair-request`，带凭据） |
| 配对确认 | `POST /api/user/pair/{code}/confirm` |
| 已配对管理 | 列表（`GET /api/user/agents`）、改名、删除配对 |
| 授权码 | 生成短期/长期、查看、作废 |
| 自动化 | 列表、启停、归档/取消归档、删除 |
| 待批审批 | 列表、批准、拒绝 |

**结论：手机 WebUI 已经能承担「让 agent 连进来 + 看部署了什么」这两件事，够用。**

---

## 二、二期清单（5 项，本期不做）

共同点：**后端早就具备能力，只是手机上没有对应界面**，属于前端补缺 + 少量聚合，不阻塞 AF 主线程。

### 1. 看单个设备当前状态
- **痛点**：站在房间里想知道灯到底是开是关、空调现在多少度，只能靠肉眼。
- **后端已有**：`GET /api/entities/{entity_id}/state`（实时优先，失败回退目录缓存并标注来源）
- **二期要做**：自动化详情里嵌一排设备状态徽标，支持下拉刷新。

### 2. 全屋设备清单
- **痛点**：没有一个「哪个房间有哪些东西」的视图。
- **后端已有**：`GET /api/entities`（全屋浏览，强制分页）、`GET /api/catalog`（按域/区域统计摘要）
- **二期要做**：按房间分组的设备页。

### 3. 按名字找设备
- **痛点**：口语名（「卧室灯」）到真实设备的对应关系，手机上查不到。
- **后端已有**：`GET /api/entities/resolve?name=&area=`（自然语言解析，带置信度分档）
- **二期要做**：搜索框 + 结果候选列表。

### 4. 手动「现在就跑一遍」
- **痛点**：写好规则后想当场试一下，现在手机上没法触发。
- **后端已有**：`POST /api/live/run`（三重闸：服务端 `AUTOFORGE_LIVE_ENABLED=1` + 服务端 HA 令牌 + 请求体 `confirm=true` 且写目标属于白名单；默认关闭）
- **二期要做**：详情页「试跑」按钮 + 二次确认勾选 + 结果反馈。**上线前必须确认三重闸仍然生效，不许为了省事绕过。**

### 5. 自动化独立详情页
- **痛点**：现在只能在列表里扫一眼，看不到一条规则完整的触发到条件到动作。
- **后端已有**：`GET /api/automations/{name}`
- **二期要做**：独立详情页（承接上面 1/4 的入口）。

## 三、为什么推到二期

主线（2026-09-24 路线图重排）优先：

1. **v1.10.0 投产收口（09-30）是第一红线**——尤其「线上代码不等于 git」这一条，任何新功能不得在它固化前上生产。
2. **AF 测试通道控制台**（开发者面板 `ui/`）还差入口：启停、看报告、一键清空。这是 AFD 主线任务，见 `docs/开发计划_用户WebUI与测试通道.md`。

上面 5 项都不在这两条关键路径上，且独立于 AF 运行时，随时可补。

## 四、需要清理（历史遗留，非二期功能）

上一轮会话曾给手机端加过一套「跟智能体对话」的功能，经复盘**方向错误、应当移除**：

- 结论依据：AF 侧不存在可被对话的智能体实体；聊天对象只可能是外部 agent（如电脑上的 opencode），而 AF 到外部 agent 没有原生推送。
- 涉及文件（待删）：
  - 前端 `ui-user-mimo/src/views/AgentChat.vue`、`AgentRuns.vue`、`composables/useAgentChat.ts`、`components/MessageBubble.vue`、`components/AgentEventCard.vue`
  - 前端路由 `router.ts` 里的 `agent-chat`、`agent-runs`
  - `AgentsView.vue` 上的「对话」按钮
  - 后端 `src/autoforge/af_chat.py` 与 `af_api.py` 中 `/api/user/agents/{id}/chat`、`/runs` 两个端点
- 注意：`af_chat.py` 曾被 scp 注入 NAS 容器，清理时务必**连同 NAS 上的文件一起删**，并按 v1.10.0 ① 固化提交，避免再次出现「线上不等于 git」。
