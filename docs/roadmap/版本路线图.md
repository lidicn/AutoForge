## 五、铁律（落地前必读）
1. **IR 唯一真相锚**：IR 字段增删先改 `ir.schema.json` 再改 Python 投影。
2. **测试由采信台真跑**：`total/collectable/ran` 由真仓实跑，不伪造通过数。
3. **文档阶段不部署**：过变更窗口 + 评审签字才合主干、才部署 NAS。
4. **零 LLM 红线**：内核不引入 `do:python`；auto-fix/深修不猜设备、不突破 canary/risk/approve。
5. **诚实铁律不可破**：EXEMPT ≠ VERIFIED（决策 B）；回滚不了 fail-closed（决策 E）。
6. **单写者租约（2026-09-30 新增）**：`forge serve` 抢不到 `{store_root}/.serve.lock` 即降级只读，写操作由 API 层统一拒绝（503），避免多实例并发写坏 store。
7. **落盘完整性（2026-09-30 新增）**：实例持久化带 SHA256 校验和，读时校验、损坏段跳过；旧格式无校验和记录向后兼容。
