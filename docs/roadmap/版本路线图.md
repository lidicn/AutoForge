### v2.0.1（决策 H，先于 v2.1）
**目标**：收口 v2.0 投产硬阻塞，让"测试由采信台真跑"铁律恢复（跑的不是真相 = 铁律失效）。工期 2–3 天。

- F0.2 文档鲜度：README/KICKOFF 仍写 488 passed，实际 v1.7.1 已 529 passed；同步 ADM 剩余项。
- **裁定（H）**：v2.0.1 完成前不启动任何 v2.1 功能开发。
- **收口状态（2026-09-27）**：六 PR（0.1-a~0.3）已合入主干 + gates 基线对齐（chore 6d334d5）；投产 + 回滚手册就位（`docs/roadmap/投产回滚_v2.0.1.md`）。代码/文档收口完成 → **决策 H 解除，v2.1 解锁**。实际 `docker compose up` 仍待 09-30 变更窗口 + 评审签字（铁律：文档阶段不部署）。

## 三、治理项（决策 G）
UI 三目录收敛：`ui-user-mimo` 为 ForgeSight 主线；`ui-user/` 冻结归档；`ui/` 运维控制台独立。下个大版本前完成归档 + 交接文档更新。

## 四、铁律（落地前必读）
1. **IR 唯一真相锚**：IR 字段增删先改 `ir.schema.json` 再改 Python 投影。
2. **测试由采信台真跑**：`total/collectable/ran` 由真仓实跑，不伪造通过数。
3. **文档阶段不部署**：过变更窗口 + 评审签字才合主干。
4. **零 LLM 红线**：内核不引入 `do:python`；auto-fix/深修不猜设备、不突破 canary/risk/approve。
5. **诚实铁律不可破**：EXEMPT ≠ VERIFIED（决策 B）；回滚不了 fail-closed（决策 E）。
