## 0 · 投产前置（必读，v2.0.1 已落地的结构性变更）

1. **`src` 已烘入镜像（PR 0.1-d）**：`Dockerfile.api` 的 `COPY src` 使后端代码随镜像固化。
   - 含义：后端变更**必须** `docker compose build` 重烘镜像才生效；旧的「挂宿主源码卷 `/app/src`」方式在 compose 中已注释（开发期热改才临时开启，生产禁用）。
   - 后果：回滚 = 回退**镜像**，不再是改卷。见 §3。
2. **token 走 secret 管理（PR 0.1-b）**：不再依赖明文 `env_file: ../.env`。
   - 读取顺序：`credentials.json` > secret 文件（`AUTOFORGE_SECRET_DIR`，默认 `/run/secrets`）> 环境变量。
   - `.env` 仍被 `.gitignore` 忽略，绝不进版本库。
3. **鉴权 fail-closed（PR 0.1-c，P0-9）**：未带合法令牌 / 令牌失效 → 三态拒绝（401/403），不再 fail-open 裸奔。
4. **两容器基线收口（PR 0.1-d）**：`sync` 服务读数与 `api` 镜像基线已对齐（sync 52 vs api 0 的分叉已解释并收口）。
5. **质量门基线对齐（chore 6d334d5）**：`gates.sh` 已对齐 `.gates-baseline.txt` 并跑通（退出码 0）。

## 2 · 部署步骤（09-30 变更窗口执行）

```bash
# 在仓库根目录（e:/NAS/AutoForge 对应 NAS 真仓 /vol1/1000/docker/autoforge）
cd /vol1/1000/docker/autoforge

# 1) 重烘镜像（src 已固化进镜像，必须 build）
docker compose -f docker/docker-compose.api.yml build

# 2) 起服务（前端 dist 经卷挂入 /ui；store 持久化在 /data）
docker compose -f docker/docker-compose.api.yml up -d

# 3) 观察启动（lifespan 含采集/对账，约 1–2 分钟才就绪，期间端口短暂 000 属正常）
docker compose -f docker/docker-compose.api.yml ps
```

前端 `ui/dist` 单独更新（无需重烘后端镜像）：
```bash
# 在 ui/ 目录构建后，把 dist scp 到 NAS 挂载点即生效
VITE_USE_MOCK=false VITE_API_BASE=/api npm run build   # 本地 ui/ 下
# scp ui/dist → /vol1/1000/docker/autoforge/ui/dist
```

> 非敏感开关（`AUTOFORGE_LIVE_ENABLED` / `AUTOFORGE_HA_URL` / `AUTOFORGE_SESSION_TTL_S`）经 `environment` 从宿主 shell env 注入；敏感 token 走 §0.2 的 secret / shell env 二选一。

## 3 · 回滚步骤（异常时）

回滚**只回退镜像与前端口**，绝不回退 `/data` store（含版本快照 / 置信度 / 审计，回退会丢真相）。

```bash
cd /vol1/1000/docker/autoforge

# 1) 后端回退到回滚锚点镜像
docker tag autoforge-api:pre-v2.0.1 autoforge-api:latest
docker compose -f docker/docker-compose.api.yml up -d

# 2) 前端回退（如需）
rm -rf /vol1/1000/docker/autoforge/ui/dist
mv /vol1/1000/docker/autoforge/ui/dist.pre-v2.0.1 /vol1/1000/docker/autoforge/ui/dist
docker compose -f docker/docker-compose.api.yml restart autoforge-api

# 3) 验证（同 §4）
```

回滚判定原则（fail-closed 延续）：
- 鉴权异常 / 质量门回归 → 立即回退镜像。
- `/data` 永不在回滚范围内（版本真相锚，单调向前）。
- 回滚后须重跑 §4 验证，确认服务回到回滚锚点行为。
