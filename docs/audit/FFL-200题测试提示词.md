## 四、intent JSON 格式

### 4.1 基础格式

```json
{
  "name": "自动化名称",
  "mode": "restart",
  "when": {
    "type": "state",
    "entity": "entity_id",
    "to": "on"
  },
  "do": {
    "action": "开灯",
    "target": "entity_id"
  }
}
```

### 4.2 触发类型

| type | 说明 | 例子 |
|------|------|------|
| `state` | 状态变化触发 | `{"type": "state", "entity": "binary_sensor.xxx", "to": "on"}` |
| `time` | 定时触发 | `{"type": "time", "at": "08:00"}` |
| `sun` | 日出日落触发 | `{"type": "sun", "event": "sunset", "offset": -1800}` |

### 4.3 动作映射

| 中文动作 | 英文动作 | 实际 HA 服务 |
|---------|---------|-------------|
| 开灯 | turn_on | light.turn_on |
| 关灯 | turn_off | light.turn_off |
| 开空调 | - | climate.turn_on |
| 关空调 | - | climate.turn_off |

### 4.4 条件（可选）

```json
"if": {
  "lt": {"var": "sensor.xxx", "const": 26}
}
```

### 4.5 询问（可选）

```json
"ask": {
  "prompt": "要关灯吗？",
  "timeout": "30s"
}
```

### 4.6 等待（可选）

```json
"wait": "5m"
```

## 六、测试流程

### 每题流程

```
1. 读 nl_prompt（自然语言需求）
2. 读 entities_hint（实体映射参考）
3. 自己翻译成 intent JSON
   - 不确定 entity_id 时，调 af_resolve_entity 查
4. 调 af_draft(intent) → 拿 ref
5. 调 af_apply(ref, stage="simulate") → 拿 build + sim 结果
   - 注意：用 stage="simulate"，不要用 stage="save"
   - stage="simulate" 会过 build + 仿真回放，但不会入待批队列
   - stage="save" 会入队，队列上限 20 条，跑 200 题会熔断
6. 对照 expect 判定 PASS/FAIL
```

### 判定标准

| expect | PASS 条件 |
|--------|----------|
| `build_ok` | af_apply 返回 ok=true，有 pending id |
| `build_error` | af_apply 返回 ok=false，有错误码 |

## 八、注意事项

### 8.1 技术注意

1. **用 Python 调 MCP，不要用 PowerShell**（JSON 序列化有问题）
2. **action 字段可以用中文**（开灯/关灯）或英文（turn_on/turn_off）
3. **stage="save"** 会入待批队列，返回 pending id
4. **stage="check"** 只过安全闸，不入队

### 8.2 翻译注意

1. 定时触发："每天早上8点" → `{"type": "time", "at": "08:00"}`
2. 日落触发："日落前半小时" → `{"type": "sun", "event": "sunset", "offset": -1800}`
3. 条件判断："如果温度超过26度" → `{"gt": {"var": "sensor.xxx", "const": 26}}`
4. 高风险设备（锁/空调）会被安全闸拦截，expect=build_error 是正常的

### 8.3 输出要求

1. 每题记录：id、nl_prompt、intent JSON、build 结果、PASS/FAIL
2. 最后统计：总数、PASS、FAIL、通过率
3. 结果保存到：`D:\Documents\WorkSpace\Test\results\ffl_af_200quiz_nl\results.json`
