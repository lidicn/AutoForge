## 四、未处理项（说明）
- **watchdog（审计优先级3）**：未实现自动重启。理由：SAFE HALT 是 TickSupervisor 的有意安全闸（连续失败 20 次后停机），自动重启会抵消该保护；本修复使线程在**非 SAFE HALT 的意外异常**下保活，SAFE HALT 仍经 `/api/health` `tick_health` 可见。如需更强自愈，建议后续单独立项（重启前需人工/监控确认，而非盲目拉起）。
- 审计声明 14 个 `out_of_scope` 单元（HTTP 鉴权 / MCP 授权 / 表达式沙箱 / `af_store` / `af_persist` / canary / `af_bus` / `af_instance` 终态 / `af_orchestrator` / `af_scanner` / HA 适配器 / `af_secrets` / CLI / `homesdk` 供应链）本轮未审，不代表安全面已覆盖。
