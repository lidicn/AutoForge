## 1. 行动前协议（两个窗口都执行，无例外）

1. **读**：`read` 本文件全文（重点 §6 当前状态、§7 最后一行流水）。
2. **判**：若 §6「锁」= **占用中** 且租约未过期 ⇒ **立即停**，只向出资人/群汇报「有窗口在动，我不动」，⛔ 不碰发版树、不 push、不部署。
3. **抢锁**：在 §7 追加一行「占用中」（窗口标识 / 时间 / 动作 / 目标 sha / 租约到期），并把 §6 锁状态改成该行内容。
4. **行动**：只做抢锁时声明的那一件事；过程中若目标 sha 变了 ⇒ 停，回第 1 步。
5. **释放**：追加「完成」行（最终 sha＋读数），把 §6 锁状态改回「空闲」。

**租约**：30 分钟。过期未释放 ⇒ 不自动回收，**只有出资人或 PM 明确指令**才把锁置回空闲，并在流水记录「强制回收＋原因」。

## 3. 冻结候选＝HEAD（推送前硬检查）

推 master 前必须现读：`origin/master` sha、发版树 HEAD、`git status --short`、本文件 §7 最后一行。四者不一致 ⇒ 停。
⛔ 中途 sha 不当冻结点；⛔ 不 rebase、不强推别人的提交；发现陌生提交按 runbook §〇「先查是谁推的、推了什么」处理。

- 群 @ 本 PM **不保证**路由到当前会话；会话**不能归档**（用户实测归档即断通道、放回才恢复）。

- ⛔ 真实令牌值/授权码值不进 commit、文档、issue、群消息；回执用 `auth_code:xx***` 掩码。

## 5. 冲突处置（发现陌生改动 / 陌生 HEAD）

停 → 读本文件 → 现读 `git log`／工作树 → 按「谁在什么时候动了什么」补齐流水 → 再决定。
⛔ 不猜测、不覆盖、不删他人提交；疑似撞车先报出资人一句，不等澄清就不动。
