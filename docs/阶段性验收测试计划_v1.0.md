## B. 节点类型专项（7 种 × 3 场景）

### B1. on 节点（4 种触发类型）

| # | 场景 | 验证点 |
|---|------|--------|
| B1-1 | state 触发（entity 状态变化） | off→on 触发，on→on 不触发 |
| B1-2 | time 触发（at:"HH:MM"） | 本地时间正确触发（B3-AF-04 回归） |
| B1-3 | sun 触发（sunset/sunrise） | 虚拟时钟推进到日落触发 |
| B1-4 | event 触发（on event） | emit→on event 跨自动化闭环 |

### B2. if 节点

| # | 场景 | 验证点 |
|---|------|--------|
| B2-1 | 单条件（is_on/is_off） | 条件真走 then，假走 no |
| B2-2 | 多条件 AND（温度>28 且 门关） | 两个条件都真才走 then |
| B2-3 | 数值比较（gt/lt/eq） | 必须 type:"numeric" 声明，否则字符串比较 |

### B3. do 节点

| # | 场景 | 验证点 |
|---|------|--------|
| B3-1 | L1 动作（灯/开关） | 直接执行，无需 confirm |
| B3-2 | L2 动作（空调/窗帘） | 强制 requires_confirm + canary |
| B3-3 | on_error 边 | 动作失败走 on_error，不直接 failed |

### B4. ask 节点

| # | 场景 | 验证点 |
|---|------|--------|
| B4-1 | yes/no 分支 | 回答"好"走 yes，"不用"走 no |
| B4-2 | on_timeout 兜底 | 超时走 on_timeout，实例不挂起 |
| B4-3 | 房间消歧义 | answer(room="study") 只命中书房 ask |

### B5. wait 节点

| # | 场景 | 验证点 |
|---|------|--------|
| B5-1 | wait 到期走 then | 不是 on_timeout（语义 A） |
| B5-2 | wait 与 for 持续条件区分 | wait 是实例定时器，for 是触发条件 |
| B5-3 | wait 后接 L2 动作 | HIGH_RISK_AFTER_SUSPEND 告警 |

### B6. set 节点

| # | 场景 | 验证点 |
|---|------|--------|
| B6-1 | 变量赋值 | set 后 if 可读变量 |
| B6-2 | 变量持久化 | persist=true 时变量跨恢复 |
| B6-3 | set 异常 | 表达式错误走 _soft_fail |

### B7. pass 节点

| # | 场景 | 验证点 |
|---|------|--------|
| B7-1 | 静默结束 | pass 后实例终态 done |
| B7-2 | 用户拒绝分支 | ask no→pass，实例终态 |
| B7-3 | on_error 兜底 | do 失败→pass，实例终态 |

## C. 安全闸专项（20 项）

> G2 已实现的 20 项检查，逐项验证"未修时 FAIL / 修后 PASS"。

| # | 检查项 | 级别 | 验证方法 |
|---|--------|------|---------|
| C1 | 高危动作 L3 + 白名单 | error | 写 L3 动作无白名单→拒 |
| C2 | ask/wait 缺 on_timeout 或 default | error | ask 无 on_timeout→拒 |
| C3 | 跨自动化实体依赖环 | error | A 写 B 读、B 写 A 读→拒 |
| C4 | 静态图内循环 | error/warning | 无终止条件循环→拒 |
| C5 | on_cancel 分支产生新实例 | error | on_cancel 里 do→拒 |
| C6 | 挂起分支内执行高风险动作 | error | ask yes 后直接 L3→拒 |
| C7 | Shadow 模式 do 写设备 | error | shadow 模式 do→拒 |
| C8 | 跨自动化读写对方实例私有变量 | error | 读他方 var→拒 |
| C9 | 适配器配置含 IR 未定义策略参数 | error | 未知参数→拒 |
| C10 | snapshot=false + 多条件 AND | warning | 告警不拦截 |
| C11 | 实体存在性校验 | error | 引用不存在实体→拒 |
| C12 | 跨自动化实体抢占冲突 | error | 两自动化写同一实体无 priority→拒 |
| C13 | L2 动作强制 canary + 人工确认 | error | L2 无 canary→拒 |
| C14 | 低置信度（<0.6）禁止写设备 | error | conf<0.6 do→拒 |
| C15 | 非幂等动作 + restart/parallel | warning | 告警 |
| C16 | 同节点同优先级边重复定义 | error | 重复边→拒 |
| C17 | do 建议有 on_error | warning | 缺 on_error→告警 |
| C18 | on_cancel 分支禁止再次挂起 | error | on_cancel 里 ask→拒 |
| C19 | 实体读写权限 ACL | error | ACL 拒绝→拒 |
| C20 | NL 覆盖率检查 | warning | 节点未被 NL 提及→告警 |

## 执行顺序

1. **C（安全闸）+ G（边界）**：本机单测，最快出结果
2. **A（端到端）+ I（交互）**：FFL 通过 MCP 执行
3. **B（节点）+ D（仿真）+ F（ask）**：FFL + 本机单测
4. **H（MCP/API）**：FFL 连通性测试
5. **E（dry-live/live）**：真机实测，最后做（需要用户在场）
