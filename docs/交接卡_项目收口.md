## 2. 行为增量（相对 G1 基线）

- 安全闭环：编译期静态闸（G2）+ 运行期置信度自主（G4）+ 灰度回滚（G4）。
- 韧性闭环：五类故障注入与四类失败落执行器断言（G5）。
- 真实价值链路：`forge run --live` 打通真机下发（白名单 + 二次确认），**canary 才真正生效**。
- 可审计：版本化存储 + diff（G6）。
- Agent 撰写面：AF-Spec 文本 → 同一份 JSON IR（G7）。
- 可续跑：`persist=true` 的活跃/挂起实例跨进程 / 崩溃恢复（`af_persist` + `run/watch --persist-dir`），定时器以墙钟落盘。
- 对外契约：CLI 扩展为 `build｜sim｜run(--live，--persist-dir)｜watch(--persist-dir)｜conf｜diff｜store｜spec`；无 IR Schema 破坏性改动。
